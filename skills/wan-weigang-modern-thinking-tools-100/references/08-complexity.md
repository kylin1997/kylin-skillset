## 八、复杂性（8）

### 8.1 生成（Generativity / Organizational Closure / Evolvability）

**何时调用**：用户想创造能超越自己生命周期的公司、学校、作品体系或共同体；事业每轮都靠创始人输血、救火和拍板；讨论传承、接班与可持续生长。

**核心模型**：生成不是留下名声，而是使一样东西获得继续生长的能力。组织闭合要求维持系统的关键环节能在内部彼此供养：成果换回下一轮资源；这一代能培养下一代；创始人不在时仍能作关键判断。可演化性要求系统不仅复制旧版本，还能产生变异、选择有效尝试、保留成功，并把局部失败隔离。真正的作品从“我在推动它”走向“它会产生我没预见的新东西”。

**Agent 程序**：1）画出资源、价值产出、人才再生产和判断四个循环；2）每当创始人补位，追问怎样让同类事情下次不再依赖他；3）建立收入/资源回流、带教与接班、剩余判断机制；4）把系统模块化，允许边缘小试、比较和组合；5）保存核心身份与安全护栏，但让方法和结构持续变异。

**诊断问题**：停止外部输血后能活多久？今天这批人能带出下一批吗？创始人离开三个月，哪些决定会停？系统是在复制自己，还是能创造更好的后代？

**边界与输出**：脱离创始人不等于抛弃起源，传承也不等于把初版永远固化；有害系统的自我延续不是价值。输出应给未闭合环、补环动作、接班结构、可演化模块、核心护栏和创始人退出梯度。

### 8.2 对称性破缺（Symmetry Breaking / Lock-in）

**何时调用**：新行业、组织、标准或身份尚未定型；许多选择看似等价但某次偶然可能锁定未来；用户想判断何时行动才能成为默认规则的奠基者。

**核心模型**：对称状态容许多个未来；细小扰动选中一个方向后，网络效应、配套、身份、训练和历史投入会把偶然冷却成难改的命运。破缺不是秩序的瑕疵，而是新秩序的生成机制。关键是判断系统温度：太热时动作只是噪声；太冷时主导设计和利益已经锁定；“将冷未冷”时可能性开始收敛却仍有多个活选项，最适合用可复制、可共同承认的动作破缺。序参量是能把无数局部选择压缩成宏观方向的关键标准、接口或身份。

**Agent 程序**：1）列仍然存活的路线、共同标准和主要依赖；2）用切换成本、网络密度、制度化程度判断可塑性；3）寻找能协调大量后续选择的序参量；4）在窗口期推出可使用的默认值、开放协议、示范项目或命名，并争取配套承诺；5）预先评估锁定错误路线的代价，尽量保留互操作和修订口。

**诊断问题**：系统还有几种可信未来？什么决定一旦选中会带着其他选择一起走？现在是太早的噪声、恰好的窗口还是已冷的锁定？默认值由谁固化？

**边界与输出**：早期影响力不等于有权把私人偏好强加众人；不可用操控制造事实。输出应给系统温度、候选路线、序参量、破缺动作、锁定收益/风险与保留选择的接口。

### 8.3 邻近可能（Adjacent Possible）

**何时调用**：远大目标看不见直接路径；用户纠结“真正的自己”或因当前选择不完美而不行动；设计学习项目、职业选择、创新路线和下一步。

**核心模型**：很多未来在当前状态根本不可想象，只有先实现一种可能性，才能进入新房间并看见下一扇门。好的下一步有三项条件：它与现有能力和资源相邻，难但够得着；完成后世界留下现实构件，如作品、原型、实战能力、合作关系或真实用户；这个构件能参与下一轮组合。邻近体现探索，留下与可组合要求利用和承诺。计划、认识、上课若没有改变外部状态，不会自动打开新可能。

**Agent 程序**：1）列当前构件：能力、作品、关系、资产、信誉与场域；2）生成比现状新一格、几周或几月能交付的项目；3）按“留下什么”和“能和什么再组合”排序；4）选择一个真投入、接触真实用户或评审的项目；5）完成后更新构件图，再从新位置选择，而非死守最初身份叙事。

**诊断问题**：这一步够得着吗？结束后除了经历和证书还剩什么？构件能被别人看见、调用或信任吗？它会打开哪两三种下一步？你是在学习准备，还是已经提交作品？

**边界与输出**：邻近可能不是短视或拒绝远景；远景用于定方向，邻近项目用于造路径。输出应给当前构件、三个候选项目、推荐项目、交付物、真实反馈入口和下一组合假设。

### 8.4 反馈回路（Feedback Loops / Closed-loop Control）

**何时调用**：复杂系统因果太多难以下手；增长停滞或失控；政策、产品、习惯需要边做边调；业务每一轮都重新求人、花钱，尚未形成飞轮。

**核心模型**：强化回路让初始变化自我放大，平衡回路反向纠偏并趋向目标；延迟会使控制者过度修正或误判无效。闭环控制不要求先知道整个系统，只需行动、可靠测量偏差、按反馈调整。正反馈只能放大“有”，不能无中生有；冷启动需人工注入第一批真实种子。启动机制可以手工、低效和补贴，运行机制必须让本轮输出成为下轮输入：作品换证据，证据换信用，信用换用户、关系、数据或现金。

**Agent 程序**：1）定义系统边界、存量、输入、输出和时间尺度；2）画出最关键的强化/平衡回路并标延迟；3）决定想启动、抑制还是稳定哪条回路；4）设计小动作与高频、贴近结果的反馈；5）冷启动时集中种子，要求首轮留下下一轮燃料，达到自持阈值后撤掉人工呼吸。

**诊断问题**：哪个存量真正在增长或衰减？本轮结果怎样进入下一轮？反馈何时到达，是否因此矫枉过正？启动燃料是真用户和真证据，还是虚假声势？

**边界与输出**：反馈会被指标操纵，强化回路也会造成泡沫和冲突升级；高风险系统需要慢回路和限幅。输出应给回路图的文字表达、主杠杆、延迟、种子、闭环指标和失控制动器。

### 8.5 自组织临界（Self-Organized Criticality）

**何时调用**：团队一潭死水或像沸水般混乱；个人长期压抑后突然崩溃；系统要兼顾信息传播、创新敏感性与稳定；安全治理需判断应否容许小波动。

**核心模型**：系统可用分支比理解扰动传播：小于一时很快熄灭，死板但稳定；大于一时不断放大，容易失控；接近一的临界边缘，信息能跨尺度传播，小波动可长出结构，系统最敏感，却恢复更慢。临界精神不是长期绷紧，而是慢慢加载、快速释放，保留多个小出口，以少数局部规则让系统自行调节。允许频繁、可承受的小故障，可能避免压力积成一次巨灾。

**Agent 程序**：1）观察消息、任务、情绪或故障平均带出多少后续事件；2）判断是亚临界、临界还是超临界；3）死板系统增加跨边界连接、小实验和发言出口，过热系统减少耦合、限流、分区并增加冷却；4）建立休息、复盘、争议和小故障的释放节奏；5）对安全关键领域刻意保持亚临界并隔离级联。

**诊断问题**：扰动会立即消失、传播适中还是指数放大？压力平时从哪里释放？小错误被及时看见还是被压住？哪个连接一断能阻止全局级联？

**边界与输出**：临界并非所有系统的最佳点，更不能浪漫化事故、躁狂或过劳；核安全等领域应留充分裕度。输出应给状态判断、分支传播线索、调热/调冷动作、释放口、隔离与恢复指标。

### 8.6 边际分析（Marginal Analysis / S-Curve / Second Curve）

**何时调用**：决定继续、加码、缩减还是换打法；飞轮看似增长却不知是在启动还是见顶；资源受沉没成本和平均回报误导；需要提前开第二增长曲线。

**核心模型**：决策看下一单位投入带来的新增收益，而非总收益或过去成本。边际效益为正且递增应加码并考虑杠杆；为正但递减仍可做，却应寻找瓶颈和第二曲线；降到零应停止新增；为负应缩减或退出。许多事业沿 S 曲线经历慢启动、加速、饱和。第二曲线必须在旧曲线仍上升、尚有现金、人才和士气时启动；等旧曲线见顶才探索往往太晚。换曲线是承认机制和局面变了，不是否定旧打法曾经正确。

**Agent 程序**：1）忽略不可追回沉没成本，定义下一单位投入和增量产出；2）用连续批次而非首尾平均计算边际变化；3）找限制增长的变量，判断调整同一曲线还是另开新曲线；4）为第二曲线划独立试验资源和验证门槛；5）设置加码、维持、转移、停止条件，防旧业务以当前利润压死新探索。

**诊断问题**：下一块钱/一天/一个人还能增加多少结果？边际回报的方向怎样？瓶颈来自需求、容量、质量还是制度？旧曲线何时不能再供养新曲线？

**边界与输出**：边际量常有延迟、网络效应和难测价值，不能因短期递减误杀长期资产。输出应给投入单位、边际序列、所在曲线阶段、瓶颈、第二曲线实验和切换阈值。

### 8.7 路径创造（Path Creation / Minimum Viable Ecosystem）

**何时调用**：旧系统被网络、配套、利益和习惯强化，直接改革阻力巨大；存量不能停机；用户需要替换技术栈、制度、流程或社会通道。

**核心模型**：真正的路径依赖是一条自我强化回路，推倒重来会同时破坏系统当前维生功能。路径创造通过“有意识的偏离”完成三个动作：造路——在旧边界外建立能独立跑通的最小可行生态，不先正面宣战；导流——存量暂留旧路，但新增用户、数据、预算和人才只进新路，阻止旧制继续繁殖；退役——新路形成网络和依赖后，分阶段关闭旧接口。支持改革者往往多而散，受损既得者少而狠，导增量能降低冲突。

**Agent 程序**：1）画旧路径的强化机制和它仍提供的必要功能；2）定义新路所需规则、技术、人才、结算和用户的最小闭环；3）在隔离空间试运行并取得真结果；4）制定“老人旧办法、新人新办法”式增量导流和迁移工具；5）达到覆盖、质量和安全门槛后逐项退役，并堵住双轨套利。

**诊断问题**：旧路靠什么越用越强？新路能否不依赖旧路的关键许可而完成一轮？哪些增量可以先导？谁会在双轨间套利？退役前必须迁走什么？

**边界与输出**：双轨期会增加成本、不公平和攻击面；新生态若不完整只是孤岛。输出应给强化回路、最小生态、隔离试点、导流规则、迁移保障、套利防线和退役表。

### 8.8 适应性循环（Adaptive Cycle / Panarchy）

**何时调用**：系统在繁荣成熟后突然崩溃；资源高度优化却越来越脆；危机后要决定保存、释放和重组什么；用户想追求“永不衰败”的组织或人生。

**核心模型**：复杂系统常在四阶段循环：开拓 r 阶段选择多、连接松、快速生长；守成 K 阶段资本积累、效率高，也因紧耦合、单一路径和去冗余而脆；释放 Ω 阶段旧结构断裂、资源脱锁；重组 α 阶段旧构件与新组合试探下一轮。不同尺度彼此嵌套成 Panarchy：小尺度危机可向上“反叛”，大尺度保存的记忆又能帮助重建。韧性不是毫发无损，而是冲击重组后仍保有核心功能、身份与反馈。

**Agent 程序**：1）判断系统在哪一阶段，并列资本、连接、选择和韧性；2）守成期保留冗余、备用供应、边缘试验和可拆模块；3）释放期先保护人、关键功能、数据、信誉和可复用资产，不强守所有旧结构；4）重组期允许多种小组合竞争，调用跨尺度记忆；5）明确什么核心必须连续、什么形式可以死亡。

**诊断问题**：系统是选择太多还是只剩一条路？效率是否通过消灭冗余换来？崩溃释放了哪些人才、资本和知识？重组后仍要保留什么身份与功能？

**边界与输出**：灾难会真实伤害人，不能把破坏浪漫化为创新；能预防的失败应预防。输出应给阶段、脆弱来源、需保冗余、危机保存清单、可释放资产和重组试验。
