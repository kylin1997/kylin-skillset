## 一、基本世界观（6）

### 1.1 叙事（Narrative）

**何时调用**：事实很多却没有方向；同一组数据引出相反行动；个人或组织不知道“我们在做什么”；情绪被某个故事牢牢占据。叙事不是装饰，而是从事实中选择主角、目标、时间顺序和因果线索，使人能够预测、赋予意义并协调行动的接口。

**核心模型**：任何叙事都做了选择。它突出一些事实、忽略另一些事实，把先后写成因果，把一个价值方向设为目标。叙事可以承载真实或虚构内容，但有用叙事必须含有可检验的因果关系，并能在新事实出现时修改。叙事有三种主要功能：压缩世界以便预测；指定“什么值得关心”以产生意义；让多人围绕共同对象协调。

**Agent 程序**：

1. 先列不依赖叙事的事实、数据、约束和未知，把评价词暂时拿掉。
2. 写出当前叙事：谁是主角，想要什么，谁或什么构成阻力，哪条因果链把现在连到未来。
3. 至少生成两个能解释同样事实的替代叙事，尤其加入一个会导向不同决定的版本。
4. 为每个叙事写出可观察预测、遗漏事实、受益者和行动倾向；用证据与后果比较，而不是按感染力选择。
5. 选一个暂时最好用的叙事，同时保留修订条件。若任务是协调，确保参与者知道目的、边界和自己的行动接口。

**诊断问题**：这是事实，还是对事实的命名？谁获得了叙事权？如果换主角、时间起点或目标函数，结论会不会改变？这个故事预测了什么？

**边界与输出**：故事不能替代证据，能动性不能变成给别人洗脑的许可证。不要把复杂冲突压成善恶剧，也不要因“一切叙事都主观”而滑向事实虚无。输出应包含“事实底板—当前叙事—替代叙事—可检验预测—行动选择”。

### 1.2 重尾分布（Heavy-Tailed Distribution）

**何时调用**：少数人、产品、事件或时段贡献大部分结果；平均数与多数人的体验明显不符；一次极端事件能改写长期成绩；用户在选择赛道、组合或曝光策略。

**核心模型**：薄尾世界的个体差异有自然上限，平均值稳定；重尾世界的尾部很长，极端值支配总量。重尾常由乘法增长、复利、优先连接、可复制信息、网络效应和“越大越容易变大”的正反馈生成。这里最重要的不是记住某个 80/20 比例，而是承认极少数结果可能比其余结果之和更重要，常规样本对尾部估计又很不可靠。

**Agent 程序**：

1. 明确结果变量，查看中位数、分位数、最大值占比和尾部，而不只报平均值。
2. 问变量是否有物理上限、是否可复制、增长是相加还是相乘，是否存在网络效应或累积优势。
3. 若是重尾，区分两类任务：防守上避免单个负尾事件毁灭；进攻上增加低成本、多样化的上行暴露。
4. 把资源配置成“保底层 + 探索层”：底层保证不出局，探索层允许多次小失败以等待少数大成功。
5. 评估路径依赖：早期微小优势是否会被反馈放大；若会，重视进入时间、分发和持续积累。

**诊断问题**：平均值代表谁？最大几个样本拿走多少总量？删掉最大值后结论是否改变？成功来自能力差异，还是可放大结构？

**边界与输出**：不能看到不平等就宣称幂律，也不能从统计分布推出道德正当性。重尾赛道可能回报巨大，也可能让多数参与者颗粒无收。输出应说明分布判断、形成机制、防毁灭措施和获取上行的方式。

### 1.3 稳态生存逻辑与文化滞后（Steady-State Survival Logic / Cultural Lag）

**何时调用**：旧观念在新环境中限制行动；人们把节俭、听话、忙碌、从众或达标本身当成美德；组织环境已经高波动，制度和心智仍按低波动时代运行。

**核心模型**：稳态生存逻辑是匮乏、弱规则和简单模型共同塑造的局部理性。匮乏带来零和、风险厌恶和“省比创造重要”；弱规则让安全依赖关系与权威，于是从众、面子和态度压过个性；简单模型把努力、指标和回报想成线性关系。物质环境变化快，文化更新慢，便形成文化滞后。旧规范曾保护生存，不等于仍适合增长。

**Agent 程序**：

1. 找出被当作天经地义的规则，并追问它最初解决的是匮乏、风险、弱规则还是协调问题。
2. 检查环境是否已改变：资源是否更丰富，规则是否更可靠，流动和波动是否上升，价值创造是否进入乘法世界。
3. 区分“仍然存在的真实风险”和“已内化的旧恐惧”。不要仅用反传统姿态代替风险计算。
4. 把姿态指标改成真实产出，把服从改成规则内能动，把一次性省钱改成长期资本，把零和防御改成可验证的正和供给。
5. 用小规模可逆实验更新观念；记录实际反馈，让新经验改写内核，而不是只在口头上宣称开放。

**诊断问题**：这条美德在什么环境下有用？今天它保护什么、牺牲什么？我们是在降低真实风险，还是维持熟悉感？指标达成后究竟创造了什么？

**边界与输出**：传统不是天然错误，现代、高波动和冒险也不是天然高级。不要羞辱处在匮乏中的人，更不能要求没有安全垫的人承担你的风险偏好。输出应给出“旧规则的历史功能—当前失配—仍需保留的部分—低风险更新实验”。

### 1.4 硬约束（Hard Constraints）

**何时调用**：宏大愿景缺少算账；计划默认资源无限、时间任意、规律会让步；领导者把别人当作无条件执行的 NPC；争论长期停在立场和热情上。

**核心模型**：硬约束是在当前问题尺度上无法靠意愿绕开的边界。课程强调四类：能量与资源守恒、时间窗口、事物自身规律、他人的能动性。预算、法律、产能、依赖关系和不可逆后果也是常见表现。硬约束不是“永远不可能”，而是要求说明改变约束的成本、路径和时间；约束越清楚，可行空间反而越可计算。

**Agent 程序**：

1. 把愿景翻译成数量：需要多少时间、钱、能量、人才、吞吐量和协调次数，规模扩大后哪项先耗尽。
2. 画约束清单，区分硬约束、暂时瓶颈、政策选择和纯粹习惯；不要把“很难”误写成自然定律。
3. 检查时间窗口与依赖：必须先满足什么，哪些步骤不能并行，延迟会不会让机会消失。
4. 把相关人视为有目标和选择的主体，推演其响应、拒绝、退出与反制，而非假定服从。
5. 在可行域内重新设计方案；若要移动约束，明确代价、证据、先导实验和失败后的恢复方式。

**诊断问题**：谁出钱，谁执行，谁承担后果？哪项守恒或容量上限被忽略？计划需要别人放弃什么？如果关键资源减半，方案是否仍成立？

**边界与输出**：尊重约束不等于保守投降；科技、制度和协作可以移动边界。但“相信”“努力”“高层支持”不是解除约束的机制。输出应呈现可行域、第一瓶颈、移动约束的代价和在边界内的最优下一步。

### 1.5 不确定性是意义的燃料（Uncertainty as Fuel）

**何时调用**：用户因未知而焦虑或要求绝对保证；计划试图消灭全部波动；生活过度确定而失去活力；需要区分哪些风险应规避、接受、利用或主动创造。

**核心模型**：不确定性可能来自随机性、混沌、计算不可约、信息不足、模型错误或其他行动者。人渴望确定，却也需要从“未知变已知”的过程获得注意、学习和意义。关键不是赞美风险，而是看收益函数：下行是否会毁灭，上行是否开放，信息能否通过行动获得。理想状态常是“一大块熟悉 + 一小块意外”。

**Agent 程序**：

1. 给不确定性分类：可通过调查减少、只能用概率表达、会被行动者改变，还是根本无法在时限内解决。
2. 分开危险与惊喜。对毁灭性下行设硬护栏、冗余和退出；对可承受的不确定性保留试错和上行。
3. 找到“确定性需求”背后的真实需要：生存、控制感、身份、责任还是避免后悔；用局部确定替代虚假全知。
4. 设计信息型行动：一次小实验既推进事情又带回证据。优先能开新选项、不会锁死未来的动作。
5. 若生活或组织过度稳态，主动加入可恢复的新任务、陌生反馈和探索配额，而不是制造无边界混乱。

**诊断问题**：未知的类型是什么？最坏结果能否承受？如果一切都确定，用户真正失去的是什么？这个行动减少未知，还是只提供心理安慰？

**边界与输出**：不确定性不是宿命论，也不是“风浪越大越该下注”。不能用成长叙事让弱者承担他人的尾部风险，更不能靠制造恐惧获取权力。输出应区分必须压低、可以承受、值得利用和应主动创造的四类不确定性。

### 1.6 三个自我（Process / Interface / Core Self）

**何时调用**：用户问“我为什么又这样”；口头决心和压力下行为不一致；想改变习惯、身份或长期能力；把一次情绪、一个角色或一段自我叙事当成固定本性。

**核心模型**：进程自我是当下感觉、念头、生理反应和行动流，像运行日志；界面自我是对自己和他人呈现的角色、性格标签与人生故事，像可更换的交互界面；内核自我是长期形成的先验、反应模式、模型参数和更新规则，决定什么会被注意、预测和奖励。改变话术或角色能改善表现，但真正成长要靠长期样本与反馈改写内核。

**Agent 程序**：

1. 把陈述拆层：此刻发生了什么进程；用户正在维持什么界面；哪种稳定先验或奖励可能在生成二者。
2. 不与情绪和人设争辩，先收集跨情境样本：什么时候会触发、身体和注意先发生什么、结果如何被奖励。
3. 若只需临场表现，改界面：设角色、脚本、环境提示和预演。若要长期改变，设计训练样本、反馈密度、重复次数和新的奖励函数。
4. 在预测落空时阻止三种逃避：忽略证据、只绕开情境、为维护身份改写事实。优先允许“原来我的模型错了”。
5. 定期审计谁在训练用户：信息流、同伴、组织文化和即时奖惩正在把内核塑造成什么。

**诊断问题**：这是一次状态、一个角色，还是跨场景稳定模式？用户想改变表现还是能力？什么行为正在被现实和群体持续奖励？

**边界与输出**：三自我是工作模型，不是已被证明的脑区划分；不要把内核说成不可改变的“真我”，也不要用身份重塑逃避责任。输出应分别给出即时调节、界面设计和长期训练方案，并说明观察内核更新的行为证据。
