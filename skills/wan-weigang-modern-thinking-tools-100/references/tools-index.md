## 一、基本世界观 → `01-basic-worldview.md`

- **1.1 叙事（Narrative）**：事实很多却没有方向；同一组数据引出相反行动；个人或组织不知道“我们在做什么”；情绪被某个故事牢牢占据。叙事不是装饰，而是从事实中选择主角、目标、时间顺序和因果线索，使人能够预测、赋予意义并协调行动的接口。
- **1.2 重尾分布（Heavy-Tailed Distribution）**：少数人、产品、事件或时段贡献大部分结果；平均数与多数人的体验明显不符；一次极端事件能改写长期成绩；用户在选择赛道、组合或曝光策略。
- **1.3 稳态生存逻辑与文化滞后（Steady-State Survival Logic / Cultural Lag）**：旧观念在新环境中限制行动；人们把节俭、听话、忙碌、从众或达标本身当成美德；组织环境已经高波动，制度和心智仍按低波动时代运行。
- **1.4 硬约束（Hard Constraints）**：宏大愿景缺少算账；计划默认资源无限、时间任意、规律会让步；领导者把别人当作无条件执行的 NPC；争论长期停在立场和热情上。
- **1.5 不确定性是意义的燃料（Uncertainty as Fuel）**：用户因未知而焦虑或要求绝对保证；计划试图消灭全部波动；生活过度确定而失去活力；需要区分哪些风险应规避、接受、利用或主动创造。
- **1.6 三个自我（Process / Interface / Core Self）**：用户问“我为什么又这样”；口头决心和压力下行为不一致；想改变习惯、身份或长期能力；把一次情绪、一个角色或一段自我叙事当成固定本性。

## 二、人生成长战略 → `02-life-growth.md`

- **2.1 能耐寻求定理（Power-Seeking Theorems / Empowerment）**：未来奖励位置不明；用户感到被单一目标、职位、关系或欲望驱使；需要在具体成果尚不确定时制定成长方向；选择会不会过早锁死未来。
- **2.2 供给侧心态（Supply-Side Mindset）**：合作讨论只剩“我该得到什么”；求职、谈判、社交或竞争陷入防御；用户想进入一个网络却没有明确贡献；隐性协作价值长期不被看见。
- **2.3 复利（Compounding）**：规划多年成长；比较学习、健康、关系、声望和金融投入；短期回报诱惑与长期积累冲突；优势容易被中断或归零。
- **2.4 自我决定理论（Self-Determination Theory, SDT）**：拖延、倦怠、最低成本合规；依赖奖惩、排名和羞耻仍缺主动性；教育或管理需要把外部任务逐步内化；用户把痛苦等同于上进。
- **2.5 自由能原理（Free Energy Principle, FEP）**：现实与预期持续冲突；用户在“改变自己还是改变环境”之间摇摆；拖延源于预期困难；需要设计恰到好处的探索、学习或适应。
- **2.6 主动高认知负荷（Active High Cognitive Load）**：高难工作被通知和会议切碎；用户大量消费信息却没有形成模型；任务看似普通，但希望从中提炼专业能力；注意力持续被低门槛刺激劫持。
- **2.7 WOOP（Wish–Outcome–Obstacle–Plan）**：愿望反复出现却没有行动；用户知道该做什么但关键时刻做不出；目标受内在习惯、恐惧或诱惑阻挡；想把意志力外包给系统。
- **2.8 社交资本、结构洞与位置（Social Capital / Structural Holes）**：能力不错却看不到机会；信息、榜样和资源密度低；两个群体彼此不理解；用户考虑迁居、换组织、跨圈合作或经营关系网络。
- **2.9 认知解耦（Cognitive Decoupling）**：愤怒、恐惧、羞耻或嫉妒正推动立即行动；脑中反复回放事件；第一解释被当成事实；冲突需要在回应前留出思考空间。
- **2.10 身份认同（Identity）**：“像我这样的人只能如此”；角色期待压过个人判断；想用身份支持习惯；阵营、职业或家庭身份使证据无法进入；需要在多个角色之间切换。
- **2.11 安全基地与安全港湾（Secure Base / Safe Haven）**：不敢探索、犯错或说真话；关系中反复焦虑追逐或冷漠回避；团队忙于甩锅；用户要求先“自律进取”，却长期处在威胁扫描中。
- **2.12 赛道选择（Game Selection）**：努力很多却回报很低；职业选择只比较岗位表面；用户没想过自己在玩什么游戏；体制内优化与自建生态位之间出现张力。
- **2.13 场域（Field / Doxa / Habitus）**：能力在一个环境中不被承认；同一行为换地方评价相反；潜规则、专业声望和权力位置影响结果；用户想进入、改变或离开某个圈层。
- **2.14 探索与利用（Exploration–Exploitation）**：在尝新与深耕间选择；当前方案不错却担心错过更好方案；职业、产品或研究需要分配探索预算；用户长期游荡或过早锁定。
- **2.15 共鸣（Resonance）**：外在成功不断升级却没有充实感；比较和享乐适应吞噬快乐；使命只剩牺牲和悲壮；用户想判断一段关系、工作或爱好是否真正有生命力。

## 三、决策与判断 → `03-decision-judgment.md`

- **3.1 无免费午餐定理（No Free Lunch Theorem）**：寻找适用于一切情境的最佳方法；方案“既要、又要、还要”；用户想等信息完备后得到唯一客观答案；价值选择被伪装成技术结论。
- **3.2 概率分布（Probability Distribution）**：只报成功率或平均收益；用一次成败评价策略；选择涉及低概率重损、高方差或不对称回报；用户问“最可能怎样”却真正关心能否承受。
- **3.3 颗粒度与因果中介（Granularity / Causal Mediator / MDL）**：解释只有口号或标签；模型细节多到无法行动；相关关系被当成因果；干预总盯最终结果，找不到可撬动环节。
- **3.4 贝叶斯先验（Bayesian Prior）**：新证据需要改变信念；罕见事件检测；判断人、消息或风险是否可信；用户在“毫无立场”和“绝不动摇”之间摆动。
- **3.5 信息价值（Value of Information, VOI）**：是否继续调研、测试或购买报告；信息焦虑和 FOMO；团队收集很多数据却不改变动作；需要选择最值得问的问题。
- **3.6 凯利公式（Kelly Criterion）**：已经判断有优势，却不知道投入多少；乘法式、可重复赌局；职业转向、项目、投资或信任需要决定仓位；用户在小利上冒命、在大机会前惜身。
- **3.7 非遍历性（Non-Ergodicity）**：总体期望很好但个人可能出局；用群体平均替个体长期命运；连续乘法风险、杠杆、债务、创业或健康选择；需要设计保险和共担机制。
- **3.8 脆弱与反脆弱（Fragility / Antifragility）**：系统面对波动；需要判断安全、韧性和成长方式；小压力是否有益；收益与损失落在不同主体；想同时做防守和捕捉重尾上行。
- **3.9 期权（Optionality / BATNA / Real Options）**：未来信息会逐步揭晓；承诺昂贵或难逆；谈判缺退路；双方对未来判断不同；项目可以分阶段学习再锁定。
- **3.10 状态杠杆（State Leverage / DSM / TOC）**：人人很忙但吞吐不增；返工和等待反复发生；任务顺序混乱；项目把精力平均撒在所有环节；需要决定“先做哪一步”。
- **3.11 选择偏差（Selection Bias）**：从成功者、名校生、现存公司、主动回应者或可见内容推断总体；怀旧；观察到样本内的奇怪相关；评估培训、基金、疗法或选拔效果。
- **3.12 回归均值（Regression to the Mean）**：极端表现后立即干预，随后指标改善；“换帅立刻见效”；一次异常被解释成趋势、天才或灾难；奖励与惩罚效果凭相邻两次表现判断。
- **3.13 前景理论（Prospect Theory）**：亏损后越赌越大；现状和买入价支配未来决定；拥有后不愿放手；同一结果换种表述就改变选择；谈判中的“本来应该有”引发强烈反应。
- **3.14 参考类预测（Reference Class Forecasting）**：工期、成本、成功率过度乐观；内部团队强调“这次不同”；用户按愿望和努力程度预测；高复杂度项目缺少可靠的单点模型。
- **3.15 超级预测（Superforecasting）**：重大未来问题边界模糊；预测成了立场表达；团队反复说“很可能”却从不结算；需要融合参考类、细节和新信息。
- **3.16 OODA 环（Observe–Orient–Decide–Act）**：信息不全而必须快速行动；对抗、危机、产品迭代或急诊场景；团队反应很快却不断重复旧动作；需要让行动本身带回信息。

## 四、学习与教育 → `04-learning-education.md`

- **4.1 认知负荷理论（Cognitive Load Theory）**：内容讲了多次仍学不会；教学材料花哨、工具很多却成绩不升；新手被要求自行发现；同一讲法让新手过载、高手无聊。
- **4.2 ICAP 框架（Interactive–Constructive–Active–Passive）**：比较学习方法；看、听、划线很多却不能迁移；设计课堂、培训或 AI 辅导；需要把学习参与度提高到当前可承受水平。
- **4.3 刻意练习（Deliberate Practice）**：从合格走向专家；经验年限增长但能力停滞；需要修复稳定弱点；区分练习、工作重复、天赋和风格。
- **4.4 表征—图式—心智模型—解释框架（Representation–Schema–Mental Model–Framework）**：读了很多却只会复述故事；进入新领域不知道该抓什么；会术语但不能推演；需要构建可迁移的知识地图。
- **4.5 综合调研（Synthesis）**：没有现成教科书却必须形成判断；需要理解半熟知识、行业争议或前沿；材料很多而结论不成形；写作、咨询、产品或政策需要“所以呢”。
- **4.6 默会知识（Tacit Knowledge）**：SOP 写得完整仍做不好；高手“知道火候”却说不清；例外、分寸、节奏和现场判断决定质量；评估 AI 或文档能否替代某种能力。
- **4.7 可取的困难与具身认知（Desirable Difficulties / Embodied Cognition）**：学习很流畅却记不住；把熬夜、羞辱和高压当刻苦；需要设计长期记忆；身心状态影响理解；比较纸笔、动作、运动和睡眠安排。
- **4.8 人力资本、信号与社交资本（Human Capital / Signaling / Social Capital）**：评估学校、学位、考试、培训或名校价值；争论教育到底教知识还是筛人；规划不同教育阶段；学历回报与真实能力脱节。
- **4.9 自主支持（Autonomy Support）**：养育、教学或管理需要内化规则；关爱变成包办和心理控制；用户投入无限时间仍焦虑；支持对象能力增长却没有退出机制。
- **4.10 拥抱与桥接（Hugging / Bridging; Near / Far Transfer）**：考试会做、现实不会；知识只在原教材措辞下被识别；培训后旧习惯复发；需要近迁移、远迁移或创造性组合。

## 五、赚钱 → `05-money.md`

- **5.1 经济租（Economic Rent）**：用户创造了很多价值却留不住收益；分析行业利润为何集中在少数环节；寻找个人、公司或产品的护城河；判断某种高利润究竟是创新回报还是封锁所得。
- **5.2 阿尔法（Alpha / Strategic Positioning）**：个人或公司只能得到行业平均回报；用户在问怎样形成差异化、战略定位或长期优势；一个曾经成功的能力开始失效；需要区分“把同一件事做得更好”和“做一套不同的事”。
- **5.3 商业杠杆（Business Leverage / Non-rival Information）**：收入与个人工时强绑定；用户想扩大业务而不同比例增加人手和成本；评估代码、内容、品牌、流程或 AI 是否真能规模化；判断高增长模式的收益和下行风险。
- **5.4 机会窗口（Window of Opportunity / Dominant Design）**：用户问某个风口是否值得进入、现在是太早还是太晚；新技术需求、叙事和供给都在变化；需要决定试探、重注、差异化切入或退出。
- **5.5 效果推理（Effectuation）**：目标和市场尚不清楚，却必须开始创业、创作或职业转向；长期计划建立在大量不可预测前提上；用户手中已有一些能力、关系和资源，可以通过行动生成机会。
- **5.6 沃德利地图（Wardley Mapping）**：团队在自制还是采购之间争论；最优秀的人被标准化事务占满；公司声称某项技术是核心竞争力，却说不清它与用户价值的关系；需要制定产品化、外包或 AI 替代路线。
- **5.7 鲍莫尔成本病（Baumol’s Cost Disease）**：教育、医疗、照护、艺术、维修和专业服务越来越贵；用户怀疑某行业“生产率落后”；需要设计服务业商业模式或判断 AI 能替代哪些部分。
- **5.8 杰文斯悖论（Jevons Paradox）**：用户断言效率提升会按比例减少资源消耗或岗位；评估 AI、自动化、节能技术带来的总需求；寻找技术降低门槛后可能出现的新产品、新任务和新职业。
- **5.9 平台（Platform / Interoperability）**：业务依赖流量入口、应用商店、外卖、电商或内容平台；分析平台为什么赢者通吃、何时从赋能转向抽租；设计双边市场或降低平台锁定风险。
- **5.10 托付（Entrustment / Uncertainty Reduction）**：用户想提升职场价值、承担更大责任或培养高级人才；组织面对模糊、昂贵、后果严重的问题；区分“技能好”与“值得授权”；评估高薪和晋升的真正依据。

## 六、社会与经济 → `06-society-economy.md`

- **6.1 地位（Social Status）**：一个看似微小的意见分歧引发强烈防御；会议、家庭或社群里出现抢话、轻蔑、服从性测试、排名焦虑；用户想建立影响力或理解群体行为。
- **6.2 礼与社会互动协议（Li / Social Interaction Protocols）**：陌生人初次合作、跨文化沟通、敏感反馈、身份次序不清、关系受损或互动成本过高；用户误把“直接”当高效，或误把礼仪当虚伪。
- **6.3 激励相容（Incentive Compatibility）**：制度依赖成员自觉或管理者威严；奖金越多行为越扭曲；规则写得很好却没人照做；需要设计绩效、市场、团队或公共机制。
- **6.4 柠檬市场与可验证性（Market for Lemons / Verifiability）**：买卖双方质量信息不对称；真正优秀的人或产品无法获得信任；组织想判断善恶、能力或合规，却只能依赖自我声明和领导印象。
- **6.5 外部性与公地治理（Externalities / Coase / Ostrom）**：行动收益归自己、成本却落到第三方；公共品没人愿付费；共享资源被过度使用；需要在私人协商、社区自治、市场工具与政府强制之间选择。
- **6.6 保护费与公共契约（Protection Racket / Public Contract）**：分析国家、平台或组织的强制权为何合法；判断税费、监管、紧急权力和公共服务是否越界；区分拥有暴力或入口的统治与受托治理。
- **6.7 软预算约束（Soft Budget Constraint）**：项目反复超支仍获追加；家庭、企业、银行或地方相信“真出事总会有人救”；大而失败者反而更易获得资源；设计救助、容错和退出方案。
- **6.8 可读性与米提斯（Legibility / Metis）**：大组织以统一表格、分类、KPI 和标准流程管理复杂现场；指标漂亮而系统变脆；一线手艺难以被总部理解；个人担心被简化成职级和数字。
- **6.9 共同知识（Common Knowledge）**：每个人似乎都知道，却没人敢先行动；团队需要同步承诺、公开结算或协调转向；理解仪式、品牌、权威、从众与沉默为何有力量。
- **6.10 替罪羊与系统（Scapegoating / Just Culture）**：事故、造假或危机后组织急着找一个坏人；同类错误反复发生；需要在系统改进与个人问责之间划线；群体把分散敌意集中到某个人或少数群体。
- **6.11 非预期后果（Unintended Consequences / Lucas Critique）**：政策、考核或家庭规则出于好意却可能事与愿违；用户用线性因果预测复杂社会；新规会改变参与者预期和策略；执行链很长且基层有裁量。
- **6.12 慢变量与稳定预期（Slow Variables / Stable Expectations）**：政府、平台或组织频繁换政策追短期成绩；参与者把精力用于猜领导而非服务用户；需要区分运营者该维护的底层秩序与市场中的快速创新。
- **6.13 摩洛克与锦标赛（Moloch / Tournament Theory）**：所有人都投入更多却无人更好；军备、加班、补习、流量和学历出现升级竞赛；个人想退出内卷，组织想减少单一排名的系统损失。
- **6.14 第三物（Third Object / Superordinate Goal）**：双方立场、身份或情绪正面冲撞；跨专业团队不共享语言和价值观；用户想推动项目却只能反复讲道理；需要在不完全共识下开始合作。

## 七、公司与领导力 → `07-company-leadership.md`

- **7.1 剩余判断权（Residual Judgment Rights）**：组织争论谁该拍板；老板事无巨细或团队遇事无人负责；合同、数据、投票和 AI 都给不出唯一答案；需要设计授权边界。
- **7.2 组织资本（Organizational Capital）**：明星人才很多却协作低效；人员一走知识就消失；坏消息到不了决策者；兼并、新团队或多人智能体需要形成共同作战能力。
- **7.3 叙事权（Narrative Power / Framing）**：组织有资源却缺共同方向；领导需要把个人判断转为集体行动；会议总在旧问题里打转；事实相同却没有一套能引导行动的解释。
- **7.4 人身依附与角色责任（Personal Dependence / Role Responsibility）**：组织靠老板恩威、亲信忠诚、裙带关系或中间人运转；权责随关系亲疏改变；外人难进入，坏消息被层层加工；需要从家长式管理走向现代治理。
- **7.5 古德哈特定律（Goodhart’s Law）**：一项指标被用于奖惩后迅速失真；团队刷量、学术计件、平台追停留时长却损害真实目标；用户既想客观评价又害怕人治。
- **7.6 指挥官意图（Commander’s Intent / Mission Command）**：现场变化快，详细计划很快过时；远程团队或智能体需要自主完成粗颗粒任务；管理者要下放手段但仍保证方向、安全和质量。
- **7.7 委托—代理（Principal–Agent Problem）**：装修、投资、医疗、外包、管理或公共治理中，执行者比委托人更懂现场；双方目标不完全一致；汇报成为唯一现实来源；需要设计监督而不陷入猜忌宫斗。
- **7.8 智件：流程、清单与经验库（Cogware / SOP / Checklist）**：组织依赖英雄救火；同类任务每人一套办法；新人不知下一步找谁；事故修完又在别处重演；需要把个人聪明转为可积累系统。
- **7.9 基线漂移（Shifting Baseline Syndrome / Normalization of Deviance）**：曾经不可接受的质量、风险、账期或服务逐渐被当成正常；破例没出事便成为先例；新人甚至不知道存在过更高标准；组织想“恢复初心”。
- **7.10 认领—授予—授权（Claiming–Granting–Authorizing Leadership）**：用户没有职位却想发挥领导作用；组织选拔管理者；优秀个人贡献者误以为业绩自然换来权力；需要让事实领导与正式权限对齐。

## 八、复杂性 → `08-complexity.md`

- **8.1 生成（Generativity / Organizational Closure / Evolvability）**：用户想创造能超越自己生命周期的公司、学校、作品体系或共同体；事业每轮都靠创始人输血、救火和拍板；讨论传承、接班与可持续生长。
- **8.2 对称性破缺（Symmetry Breaking / Lock-in）**：新行业、组织、标准或身份尚未定型；许多选择看似等价但某次偶然可能锁定未来；用户想判断何时行动才能成为默认规则的奠基者。
- **8.3 邻近可能（Adjacent Possible）**：远大目标看不见直接路径；用户纠结“真正的自己”或因当前选择不完美而不行动；设计学习项目、职业选择、创新路线和下一步。
- **8.4 反馈回路（Feedback Loops / Closed-loop Control）**：复杂系统因果太多难以下手；增长停滞或失控；政策、产品、习惯需要边做边调；业务每一轮都重新求人、花钱，尚未形成飞轮。
- **8.5 自组织临界（Self-Organized Criticality）**：团队一潭死水或像沸水般混乱；个人长期压抑后突然崩溃；系统要兼顾信息传播、创新敏感性与稳定；安全治理需判断应否容许小波动。
- **8.6 边际分析（Marginal Analysis / S-Curve / Second Curve）**：决定继续、加码、缩减还是换打法；飞轮看似增长却不知是在启动还是见顶；资源受沉没成本和平均回报误导；需要提前开第二增长曲线。
- **8.7 路径创造（Path Creation / Minimum Viable Ecosystem）**：旧系统被网络、配套、利益和习惯强化，直接改革阻力巨大；存量不能停机；用户需要替换技术栈、制度、流程或社会通道。
- **8.8 适应性循环（Adaptive Cycle / Panarchy）**：系统在繁荣成熟后突然崩溃；资源高度优化却越来越脆；危机后要决定保存、释放和重组什么；用户想追求“永不衰败”的组织或人生。

## 九、高观点反思 → `09-high-level-reflection.md`

- **9.1 零阶道理（Zeroth-Order Truth）**：讨论充满都正确的小道理，却无法决定主次；用户被边角风险、宏观新闻或精致反例劫持；需要抓住一个决策的方向和量级。
- **9.2 目标函数（Objective Function / Orthogonality / Instrumental Convergence）**：用户追问人生、组织或 AI 唯一应该最大化什么；工具理性很强却目标不清；有人试图从自然事实、智力或效率直接推出价值结论。
- **9.3 二阶意愿与元表征（Second-order Volition / Metarepresentation）**：用户同时有互相冲突的欲望；做完某事总后悔；身份、习惯或问题框架像自动驾驶；需要的不只是改答案，而是决定由哪个欲望、哪道题作主。
- **9.4 副产品与迂回（By-product / Obliquity）**：越追求睡眠、灵感、幸福、爱情、信任、声望或自然表现，状态越差；指标监控使用户紧张；外在奖励只换来表演和迎合。
- **9.5 自我约束（Self-Binding / Commitment Device）**：用户需要别人把钱、权限、信息或未来交给他；承诺因可随时反悔而不可信；权力过大、品牌边界模糊或组织需要获得长期信用。
- **9.6 道德的可扩展性（Moral Scalability）**：把公司说成家庭、把亲情规则用于公共资源、要求陌生人互爱，或反过来用合同和绩效管理家人；一项美德扩大尺度后变成偏私、腐败或低效。
- **9.7 立题（Problem Finding / Agenda Setting）**：用户长期只答考试、KPI、舆论或对手给的题；团队高效解决错误问题；需要从执行者升级为定义问题、设计游戏和分配注意力的人。
- **9.8 内部优化器（Mesa-Optimizer / Inner Alignment）**：人、组织或智能体表面完成任务却反复钻规则；训练期表现良好、部署后行为变样；岗位从解决外部问题转向证明自身必要；用户想判断真实目标而非听表态。
- **9.9 奇点前后的稀缺（Scarcity Before and After the Singularity）**：AI 让文字、代码、分析或图像产出迅速便宜，用户担心个人价值消失；寻找在丰富时代仍然稀缺的职业位置与人生价值。
- **9.10 预训练与后训练（Pretraining / Post-training）**：用户学过工具却临场想不起来；知识丰富但第一次出手不稳定；设计阅读、实践、反馈和习惯训练；判断掌声式反馈是否正在训练迎合。

## 十、结课：第100讲 → `10-closing.md`

- **100 探索和生发（Exploration and Generativity）**：用户在满足基本需要后追问人生意义、长期事业和应留下什么；多个方向都不违背硬约束，却没有外部排行榜替他选择；需要把零散尝试变成能持续生长的创造。
